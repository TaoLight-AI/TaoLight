# 桃紫有光 TaoLight AI
# 微信小程序信息架构 IA V1.0

## 1. 产品定位

第一阶段微信小程序：

以齐天大圣数字角色为核心，为平谷桃农提供低门槛的AI内容创作能力。

用户通过微信授权登录，建立个人作品空间。

核心流程：

登录 → 创建作品 → 上传素材 → 大圣创作 → 查看成果。

---

# 2. 登录设计

## 选择方案

B方案：微信授权登录。

原因：

1. 建立用户身份体系；
2. 保存用户作品；
3. 支撑未来创作者联盟；
4. 支撑MCN合作和分润体系。

首次进入：

微信授权 → 创建用户档案 → 进入桃园首页。

---

# 3. 首页：首页·大圣桃园

## 核心目标

让用户第一次进入就感受到：

“大圣不是来表演的，是来帮助我的。”

## 页面元素

- 桃园场景背景；
- 桃仙大圣数字角色；
- 欢迎语；
- 开始创作按钮；
- 我的作品入口；
- 示例作品展示。

## 大圣首次出现台词

“老孙来也！从今天开始，你负责种好你的桃，剩下的交给俺。”

---

# 4. 创作中心

用户选择创作目标。

第一版功能：

## 我要卖桃

生成产品营销内容。

## 我要讲桃故事

生成桃农人物故事。

## 我要宣传桃园

生成乡村文旅内容。

## 我要做品牌

生成品牌故事和传播方案。

---

# 5. 产品资料输入

用户填写：

- 桃子名称；
- 品种；
- 产地；
- 成熟时间；
- 口感特点；
- 桃农故事；
- 希望传递的信息。

支持：

- 图片上传；
- 视频上传；
- 语音输入。

---

# 6. 大圣AI创作流程

## 第一步：理解桃子

AI分析产品特点。

## 第二步：选择创作方向

生成多个内容主题。

## 第三步：大圣创作

输出：

- 视频标题；
- 创意方案；
- 剧本；
- 分镜；
- 发布文案。

## 第四步：作品交付

输出最终内容方案。

---

# 7. 我的作品

用户管理：

- 已生成作品；
- 草稿；
- 历史版本；
- 发布记录。

# 9. MVP原则

第一版只验证：

一个用户

一个行业

一个数字角色

一个完整创作闭环。

目标：

让桃农能够通过大圣，在几分钟内获得一套营销内容方案。
