# V5 产品决策：从健康看板收缩为训练副驾

## 唯一刚需

中年用户不是缺少课程、知识或鼓励，而是在真实训练现场仍需要自己记忆上次表现、决定本组重量和次数、处理疲劳或器械占用，并判断今天是否练得有效。

V5只解决一件事：**记住上次，带完这次，决定下次。**

## 同类边界

| 产品 | 已经做好的事情 | V5不重复建设 |
|---|---|---|
| Keep | 海量课程、吃练睡、设备数据、AI教练与社区 | 不做内容平台和全健康入口 |
| 训记 / Hevy | 自由记录每组重量次数、计划与统计 | 不做面向硬核用户的复杂自定义 |
| Fitbod / Hevy Trainer | 自动计划、恢复估计与渐进超负荷 | 不频繁重排完整计划 |
| Caliber | App加真人教练的高接触服务 | 首期只为异常保留人工升级接口 |

## 差异化机制

1. 训练前只问“今天比平时怎样”，直接决定正常版、20分钟保底版或安全停止。
2. 训练中一次只显示当前一组；首次填写重量次数，以后自动沿用。
3. 做完一组只反馈“偏轻、正好、偏重、不适”，下一组立即调整。
4. 器械被占时一键换为同肌群动作，不让用户离开流程搜索。
5. 完成后不生成空泛鼓励，只显示工作组、有效余力、同类训练变化和下次处方。
6. 不以连续打卡制造压力；恢复和20分钟保底版都属于有效执行。

## 科学边界

- 一致执行优先于复杂计划；主要肌群每周至少训练两次是通用方向。
- 进阶可通过增加重量或次数完成，系统每次只调整一个变量。
- 低训练量仍可能改善中老年人的身体功能，因此疲劳日采用最小有效剂量而非补偿训练。
- AI不诊断疾病。胸痛、晕厥、明显呼吸困难、突发视力变化或异常疼痛触发停止运动与线下评估。

## 验收标准

- 老用户打开后5秒内看见今天是否训练以及第一项动作。
- 第一次训练每组最多填写重量和次数；第二次同类训练默认自动沿用。
- 一次“偏重”使下一组重量约降低10%；一次“不适”立即结束训练并冻结进阶。
- “只有20分钟”将训练缩为两个动作、每个一组，不产生第二天叠加强度。
- 训练完成后必须生成可追溯成绩单，不能只复述用户刚选择的结果。
- 页面不出现虚构的达成概率、青春热度精确分数或无后续用途的数据输入。
