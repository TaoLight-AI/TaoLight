# 桃紫有光 AI 模型选型基准 V1

目标：不用参数排行榜选模型，而是用同一个“大圣探桃”真实案例做同题测试。

## 固定测试输入
- 地点：北京平谷桃园
- 产品：瑞蟠25
- 角色：中年、略发福的大圣，桃粉系布衣，拿自拍杆，松弛但保留猴王气场
- 内容：边走边和桃农聊天；到树前摸桃、闻桃；征得同意后摘一颗咬一口；继续自拍；少量轻咳/扶腰/小幽默
- 情绪：治愈、田间生活、种田文松弛感
- 禁止：喊麦、战斗、廉价国潮、过度电影化、站桩卖货

## 图像候选
1. wan2.7-image-pro：主测，强调角色一致性、文字与品牌色控制
2. qwen-image-2.0-pro：对照，测试封面标题与角色稳定性
3. z-image-turbo：低成本快速草图，仅作为批量预览候选

## 视频候选
1. wan2.7-i2v-2026-04-25：首尾帧/图生视频主测
2. happyhorse-1.1-i2v：15秒有声图生视频对照
3. wan2.7-r2v-2026-06-12：角色参考生视频候选，重点测试大圣一致性

## 六项评分（每项10分）
- 大圣角色一致性
- 手机自拍Vlog真实感
- 动作自然度（走、聊、摸、摘、咬）
- 平谷田间真实感
- 情绪与故事感
- 单条成本/速度

总分60。角色一致性或真实感低于7分直接淘汰，不因低价入选。

## MVP推荐策略
故事核：qwen3.7-plus（需要更低成本时切qwen3.6-flash）
海报：wan2.7-image-pro；批量试稿可切z-image-turbo
视频：先做wan2.7-i2v与happyhorse-1.1-i2v双测，再决定默认模型

## 测试纪律
每家模型使用同一故事核、同一角色参考图、同一构图和时长。不得针对某一家额外优化Prompt后再比较。保留原始输出、耗时、费用和失败次数。
